# ClauseGuard | Presentation Layer

An enterprise-grade interface engineered for legal risk assessment and executive-level auditing. Built on Next.js with Turbopack and Tailwind CSS, this presentation layer converts raw extraction streams into structured risk telemetry.

---

## ❖ Design System & UX

* **Dynamic Risk Telemetry:** Real-time data visualization mapping backend categorical risk levels into structured, scannable indices.
* **Editorial Typography:** Enforces formal serif hierarchy, algorithmic paragraph structures, and legal-grade layout rules to format raw extracted text as executive documentation.
* **Hardware-Accelerated Interaction:** Hydration-safe mouse tracking for reactive spotlight gradients and pure CSS `mask-image` rules for high-performance layout containment.
* **Direct-to-Print Engine:** Tailored `@media print` stylesheets that strip interactive chrome and standardize typography for physical A4 audit generation.

---

## ▸ Local Environment

```bash
# Install dependencies
npm install

# Initialize Turbopack development server
npm run dev
```

Navigate to `http://localhost:3000`. Ensure the FastAPI backend is running concurrently to ensure live telemetry streaming and prevent hydration fallbacks.
